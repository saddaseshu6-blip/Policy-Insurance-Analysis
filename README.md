# Title : Policy-Insurance-Analysis
## Objective :
To analyze insurance policy and customer data using Excel, SQL, Power BI, and Tableau to identify customer demographics, policy preferences, payment methods, and claim patterns. The project aims to transform raw data into meaningful insights through data cleaning, SQL queries, and interactive dashboards to support data-driven business decisions and improve insurance business performance.
Tools : Excel,Power BI ,Tableau,SQL

--- Questions we find out by using the dataset

(1)- Find out Average_coverage amount ?
(2) - Total_claim amount ?
(3)- how many policies are active  and current policy percentage ?
(4) - Total policies by status?
(5) - Age_group wise policies?
(6) - Gender wise policies?
(7) - Yearly_growth_rate and average growth_rate?
(8)-  IS Growth trend is increasing or decreasing ?
(9) - Find Ending year policies ?
